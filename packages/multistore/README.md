# prestashopheaven/runtime-multistore

Multistore helpers of a PrestaHaven module: converts the module's shop constraint to and from PrestaShop's.

## Use when

Infrastructure or a controller turns the module's ShopConstraint into PrestaShop's ShopConstraint (configuration per shop, grids, forms) or reads the shop context back into one.

## Install

```
composer require prestashopheaven/runtime-multistore
```
